Sobre o Projeto

Desenvolvido especialmente para o Projeto Agrinho, este protótipo propõe uma solução ética e tecnológica para o manejo de pragas aviárias e pequenos roedores em hortas comunitárias e escolares.

Diferente dos espantalhos tradicionais — aos quais os animais se habituam rapidamente —, o Espantalho Robótico permanece estático e economizando energia, ganhando vida (emitindo sons e movendo-se) apenas quando o sensor ultrassônico detecta uma aproximação indesejada.

Lista de Componentes

  • 1x Placa Arduino Uno
  • 1x Sensor Ultrassônico HC-SR04
  • 1x Micro Servo Motor 9g SG90
  • 1x Buzzer Ativo 5V
  • Protoboard e Cabos Jumpers
  • Sucata e Garrafas PET (Design do boneco)
